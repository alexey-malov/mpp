## Задания

### Задание 1. Мини-калькулятор — **30 баллов**

Напишите программу на языке C, которая реализует простой калькулятор для работы с целыми числами.

#### Требования к программе

1. Программа должна запросить у пользователя:
   - первое целое число
   - знак операции (`+`, `-`, `*`, `/`)
   - второе целое число
2. В зависимости от введённой операции программа должна выполнить соответствующее действие и вывести результат.
3. Обработка операций должна быть реализована с использованием конструкции `switch`.
4. Если пользователь ввёл неизвестный знак операции, программа должна вывести сообщение об ошибке.
5. Если выбрана операция деления, необходимо проверить деление на ноль.
   В случае деления на ноль программа должна вывести сообщение об ошибке и не выполнять операцию.

---

#### Пример работы программы

```txt
Enter expression: 12 + 5
Result: 17
```

```txt
Enter expression: 10 / 0
Error: division by zero
```

```txt
Enter expression: 7 ^ 2
Error: unknown operation
```

---

#### Бонус за многократное выполнение программы в цикле — **10 баллов**

Сделайте так, чтобы программа выполнялась в цикле и позволяла выполнять вычисления несколько раз подряд.
Завершение программы должно происходить по специальной команде пользователя
(при вводе символа `q` вместо первого аргумента).

```txt
Enter expression (or q to quit): 12 + 5
Result: 17
Enter expression (or q to quit): q
```

#### Бонус за вычисление длинных выражений без учёта приоритета — **30 баллов**

Расширьте программу так, чтобы она умела вычислять выражение, содержащее несколько операций подряд,
выполняя их **строго слева направо** (без учёта приоритета `*` и `/`). Например, для ввода `5 + 3 - 4 / 2`
программа должна посчитать `((5 + 3) - 4) / 2` и вывести `2`.

**Подсказка по вводу:** можно считать первое число через `scanf("%d", &result)`,
а затем в цикле читать оператор через `getchar()` и следующее число через `scanf("%d", &next)`.
После `scanf` в потоке могут оставаться пробелы и перевод строки,
поэтому перед чтением оператора пропускайте пробелы,
а завершайте ввод, если оператор оказался `'\n'` или `EOF`.

### Задание 2. N чисел наоборот — **20 баллов**

#### Условие

Напишите программу, которая:

1. Считывает целое число `N`
   (гарантируется: `0 ≤ N ≤ 100`).
2. Затем считывает `N` целых чисел.
3. Выводит эти же числа в обратном порядке, разделяя их пробелами.

---

#### Требования

- Использовать статический массив фиксированного размера (например, `int numbers[100];`).
- Не использовать динамическую память.
- Не использовать дополнительные массивы.
- Если `N == 0`, программа ничего не выводит.

---

#### Формат ввода

```txt
N
a1 a2 a3 ... aN
```

Числа могут вводиться в одной строке или в нескольких строках.

---

#### Формат вывода

```txt
aN a(N-1) ... a1
```

Числа выводятся через пробел.
Допустим перевод строки в конце вывода.

---

#### Примеры

Ввод:

```txt
5
10 20 30 40 50
```

Вывод:

```txt
50 40 30 20 10
```

```txt
3
```

```txt
100 -1 7
```

---

##### Пример 3

```txt
0
```

Вывод:


### Задание 3. Числа больше среднего — **20 баллов**

#### Условие

Напишите программу, которая:

1. Считывает целое число `N` (`0 ≤ N ≤ 10`).
2. Затем считывает `N` целых чисел.
3. Вычисляет **среднее арифметическое** этих `N` чисел и выводит **все числа, которые строго больше среднего**,
   в том же порядке, в котором они были введены.

Если `N = 0`, программа ничего не выводит.

---

#### Требования

- Использовать статический массив фиксированного размера (например, `int a[10];`).
- Не использовать типы с плавающей запятой (`float`, `double`).
- Выводить найденные числа через пробел (допустим перевод строки в конце).
- Если чисел, больших среднего, нет — не выводить ничего.

---

#### Как сравнивать без `double` (подсказка)

В C деление целых чисел отбрасывает дробную часть (например, -10 / 3 даёт -3, а не -3.333...).
Поэтому проверка $a_i > \frac {sum} N$ может дать неверный результат, особенно при отрицательном среднем.
Сравнение $a_i * N > {sum}$ корректно работает без округления и правильно обрабатывает отрицательные значения.

---

#### Формат ввода

```txt
N
a1 a2 ... aN
```

Числа могут вводиться в одной или нескольких строках.

---

#### Формат вывода

Выведите все числа `ai`, для которых `ai` строго больше среднего, через пробел.

---

#### Примеры

##### Пример 1

Ввод:

```txt
5
1 2 3 4 5
```

Сумма = 15, среднее = 3.
Вывод:

```txt
4 5
```

##### Пример 2 (с отрицательным средним)

Ввод:

```txt
4
-10 0 1 1
```

Сумма = -8, среднее = -2.
Числа строго больше -2: `0 1 1`
Вывод:

```txt
0 1 1
```

##### Пример 3

Ввод:

```txt
0
```

Вывод:

```txt
```

(Ничего не выводится).

### Задание 4. Утолщить картинку — **50 баллов**

#### Условие

Напишите программу, которая считывает из стандартного ввода «картинку» размером **10×10**.

- Символ `#` означает включённый пиксель.
- Символ `.` означает выключенный пиксель.

Нужно построить новую картинку 10×10, в которой изображение **утолщено**:
для каждого включённого пикселя исходной картинки нужно включить пиксели **слева, справа, сверху и снизу**
(если такие клетки существуют внутри изображения).

То есть каждый `#` в исходной картинке превращается в «крест» из пяти клеток: сам пиксель и до 4 соседей по сторонам.

---

#### Важные правила

1. Утолщение выполняется **по исходной картинке**: новые пиксели, появившиеся из-за утолщения,
   **не должны** порождать дополнительное утолщение.
2. Нельзя выходить за границы изображения. Если пиксель находится на краю, «сосед» за пределами картинки игнорируется.
3. Символы ввода гарантированно только `#` и `.`.

---

#### Формат ввода

10 строк по 10 символов в каждой.

Пример:

```txt
.......... 
....#.....
.......... 
.......... 
.......... 
.......... 
.......... 
.......... 
.......... 
.......... 
```

(Пробелов в конце строк нет, показаны только для наглядности.)

---

#### Формат вывода

Выведите 10 строк по 10 символов — утолщённую картинку.

---

#### Пример

##### Ввод

```txt
..........
....#.....
..........
..........
..........
..........
..........
..........
..........
..........
```

##### Вывод

```txt
....#.....
...###....
....#.....
..........
..........
..........
..........
..........
..........
..........
```

---

#### Подсказка

Удобно считать исходную картинку в массив `in[10][10]`, затем создать массив результата `out[10][10]`,
заполнить его точками и для каждого `#` в `in` выставлять `#` в нужных клетках `out`.

### Задание 5. Выделение краёв — **50 баллов**

Напишите программу, которая считывает из стандартного ввода «картинку» размером **12×12** и строит новую картинку,
в которой отмечены **краевые пиксели**.

- Символ `#` означает включённый пиксель.
- Символ `.` означает выключенный пиксель.

Клетка считается **краевой**, если:

- в исходной картинке в этой клетке стоит `#`, и
- среди **8 соседей** (по сторонам и по диагоналям) есть хотя бы один выключенный пиксель `.`
  **или сосед находится за пределами картинки**.

Иначе клетка не краевая.

---

#### Формат ввода

12 строк по 12 символов в каждой (`#` или `.`).

#### Формат вывода

- `#` — краевой пиксель

#### Важные правила

- Вычисления делайте **по исходной картинке**, результат выводите отдельно. Нельзя изменять картинку «на месте».
- Если пиксель находится на границе изображения, отсутствующие соседи считаются выключенными (`.`),
  то есть такой пиксель может стать краевым.
- Пиксели `.` никогда не становятся `#` в результате.

```txt
............
............
```

##### Вывод

```txt

....####....

....####....
............
............
............
............
```

### Задание 6. Какие клетки под атакой — **150 баллов**

#### Входные данные

На стандартный ввод подаются **8 строк по 8 символов** — текущее состояние шахматной доски.

Обозначения:

- `.` — пустая клетка
- `N` / `n` — конь (белый / чёрный)
- `R` / `r` — ладья (белая / чёрная)

Цвет фигур:

- **заглавные** буквы — белые
- **строчные** буквы — чёрные

Гарантируется, что во входных данных встречаются только символы `.`, `N`, `n`, `R`, `r`.

---

#### Правила атаки (что считать «атакуемой клеткой»)

##### Общие правила

1. Фигура атакует **только фигуры противоположного цвета** и пустые клетки на пути атаки.
2. **Свои фигуры не считаются атакуемыми** и не должны помечаться `*`.
3. Для дальнобойной фигуры (ладьи) действует **блокирование**:
   она атакует клетки по направлению движения до первой встретившейся фигуры (любой).
   Дальше атака в этом направлении не идёт.
4. Для коня блокирование не действует: он «перепрыгивает» через фигуры.

##### Конь

Конь атакует клетки, которые находятся на расстоянии:

- 2 по вертикали и 1 по горизонтали, или
- 2 по горизонтали и 1 по вертикали.

```txt
........
*.*.....
...*....
.N......
...*....
*.*.....
........
........
```

##### Ладья

Ладья атакует клетки по горизонтали и вертикали:

- вверх/вниз/влево/вправо
- до края доски **или до первой фигуры**, которая блокирует дальнейшую атаку.

```txt
..*.....
..*.....
..*.....
**R*****
..*.....
..*.....
..*.....
..*.....
```

---

#### Что нужно сделать

Ваша программа должна построить **две доски атак**:

1. доска клеток, атакуемых **белыми**
2. доска клеток, атакуемых **чёрными**

---

#### Формат вывода

Нужно вывести **две доски 8×8**, каждая — 8 строк по 8 символов.

##### Первая доска — атаки белых

- `*` — клетка атакована белыми (включая клетки с чёрными фигурами)
- `.` — пустая клетка, не атакована
- `N` или `R` — белые фигуры выводятся как есть (они не помечаются `*`)
- `n` или `r` — чёрные фигуры выводятся как есть, если они **не атакованы**, и заменяются на `*`, если атакованы

После первой доски вывести пустую строку (одна строка перевода строки), затем вторую доску.

##### Вторая доска — атаки чёрных

Аналогично:

- `*` — клетка атакована чёрными (включая клетки с белыми фигурами)
- `.` — пустая клетка, не атакована
- `n` или `r` — чёрные фигуры выводятся как есть
- `N` или `R` — белые фигуры выводятся как есть, если не атакованы, и заменяются на `*`, если атакованы

---

#### Примечания

- Доска фиксированного размера 8×8.
- Индексация клеток и работа с границами — ответственность программиста.
- Рекомендуется хранить входную доску в двумерном массиве и отдельно формировать две карты атак
  (например, два массива 8×8 из 0/1).

#### Бонус за поддержку других типов фигур — **50 баллов**

В дополнение к базовой реализации (конь и ладья) необходимо добавить поддержку следующих фигур:

- `B` / `b` — слон
- `Q` / `q` — ферзь
- `P` / `p` — пешка

Цвет фигур:

- Заглавные — белые
- Строчные — чёрные

Все правила цвета и вывода остаются теми же, что и в основной части задания.

---

##### Слон (B / b)

###### Правила атаки

Слон атакует по диагоналям:

- вверх-влево
- вверх-вправо
- вниз-влево
- вниз-вправо

Атака продолжается:

- до края доски
- или до первой встретившейся фигуры

Если встретилась:

- фигура противника → клетка помечается `*`, дальше атака в этом направлении прекращается
- своя фигура → клетка **не помечается**, атака прекращается

---

##### Ферзь (Q / q)

Ферзь объединяет правила ладьи и слона.

Он атакует:

- по горизонтали
- по вертикали
- по диагоналям

С теми же правилами блокирования.

---

##### Пешка (P / p)

###### Важно: пешка атакует не так, как ходит

Белая пешка (`P`) атакует:

- по диагонали вверх-влево
- по диагонали вверх-вправо

Чёрная пешка (`p`) атакует:

- по диагонали вниз-влево
- по диагонали вниз-вправо

Особенности:

- пешка атакует только **одну клетку по диагонали**
- атака возможна только в пределах доски
