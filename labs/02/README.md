## Критерии оценивания работы

- Для получения оценки "удовлетворительно" нужно набрать не менее X баллов.
- На оценку "хорошо" нужно набрать не менее Y баллов.
- Для получения оценки "отлично" нужно набрать не менее Z баллов.

## Задания

### Задание 1. Мини-калькулятор — 30 баллов 

Напишите программу на языке C, которая реализует простой калькулятор для работы с целыми числами.

#### Требования к программе

1. Программа должна запросить у пользователя:
   - первое целое число
   - знак операции (`+`, `-`, `*`, `/`)
   - второе целое число
2. В зависимости от введённой операции программа должна выполнить соответствующее действие и вывести результат.
3. Обработка операций должна быть реализована с использованием конструкции `switch`.
4. Если пользователь ввёл неизвестный знак операции, программа должна вывести сообщение об ошибке.
5. Если выбрана операция деления, необходимо проверить деление на ноль.
   В случае деления на ноль программа должна вывести сообщение об ошибке и не выполнять операцию.

---

#### Пример работы программы

```txt
Enter expression: 12 + 5
Result: 17
```

```txt
Enter expression: 10 / 0
Error: division by zero
```

```txt
Enter expression: 7 ^ 2
Error: unknown operation
```

---

#### Бонус за многократное выполнение программы в цикле — 10 баллов

Сделайте так, чтобы программа выполнялась в цикле и позволяла выполнять вычисления несколько раз подряд.
Завершение программы должно происходить по специальной команде пользователя
(при вводе символа `q` вместо первого аргумента).

```txt
Enter expression (or q to quit): 12 + 5
Result: 17
Enter expression (or q to quit): q
```

#### Бонус за вычисление длинных выражений без учёта приоритета — 30 баллов

Расширьте программу так, чтобы она умела вычислять выражение, содержащее несколько операций подряд,
выполняя их **строго слева направо** (без учёта приоритета `*` и `/`). Например, для ввода `5 + 3 - 4 / 2`
программа должна посчитать `((5 + 3) - 4) / 2` и вывести `2`.

**Подсказка по вводу:** можно считать первое число через `scanf("%d", &result)`,
а затем в цикле читать оператор через `getchar()` и следующее число через `scanf("%d", &next)`.
После `scanf` в потоке могут оставаться пробелы и перевод строки,
поэтому перед чтением оператора пропускайте пробелы,
а завершайте ввод, если оператор оказался `'\n'` или `EOF`.
