### Задание 1: анализ программы на ассемблере Intel 8080 — **30 баллов**

Вам дана функция на ассемблере **Intel 8080**. Код функции приведён ниже:

```asm
Fn:
        MOV A, D
        MVI D, 00H

        LXI H, 0000H
        MVI B, 08H

Loop:
        DAD H
        ADD A

        JNC Skip

        DAD D

Skip:
        DCR B
        JNZ Loop

        RET
```

#### Ваша задача

1. Для каждой инструкции написать комментарий, что она делает.

2. Определить:

   - в каких регистрах функция получает входные данные;
   - в каких регистрах возвращает результат;
   - какие регистры изменяются во время работы функции.

3. Отассемблировать программу в машинный код и прогнать её под эмулятором, наблюдая за изменением значений регистров и флагов.

4. Написать эквивалентную программу на языке C.

5. Объяснить словами, что делает эта функция.

### Задание 2: программа echo для CP/M — **50 баллов**

Напишите программу на ассемблере Intel 8080, работающую в операционной системе **CP/M**.

Программа должна:

- считывать символ с клавиатуры
- выводить этот же символ на экран
- повторять это в цикле

Программа должна завершить работу, если пользователь нажал клавишу **Enter**.

#### Требования

1. Реализовать цикл обработки ввода:

   - чтение символа
   - проверка условия завершения
   - вывод символа

2. Программа должна корректно завершаться и возвращать управление операционной системе.

3. Программа должна быть оформлена как исполняемый `.COM`-файл (начало с адреса `100h`).

#### Особенности

- клавиша **Enter** соответствует символу с кодом `0Dh`
- этот символ не должен выводиться — программа должна завершиться

#### Что нужно реализовать

Алгоритм программы:

```text
цикл:
    считать символ
    если символ == Enter → завершить программу
    вывести символ
    перейти к началу цикла
```

### Задание 3: разворот строки (Reverse String) — **70 баллов**

Напишите программу на ассемблере Intel 8080, работающую в операционной системе **CP/M**.

Программа должна:

1. Считать строку с клавиатуры

   - максимальная длина строки — **20 символов**
   - ввод завершается нажатием клавиши **Enter**

2. Развернуть строку (поменять порядок символов на обратный)

3. Вывести полученную строку на экран

---

#### Требования

##### Ввод строки

- строка должна быть сохранена в памяти
- символ **Enter (0Dh)** не входит в строку

##### Обработка строки

Реализуйте подпрограмму:

```text
ReverseStr
```

###### Параметры

- `HL` — адрес начала строки
- `BC` — длина строки

###### Задача

Развернуть строку **на месте** (in-place), не используя дополнительную память.

---

##### Вывод строки

- вывести строку после разворота
- вывод должен соответствовать новой последовательности символов

#### Алгоритм (идея)

- считать строку
- определить её длину
- вызвать ReverseStr
- вывести строку

#### Подсказка к ReverseStr

Можно использовать два указателя:

- левый  → начало строки
- правый → конец строки

И менять символы местами:

```text
пока left < right:
    swap(*left, *right)
    left++
    right--
```

#### Ограничения

- не использовать дополнительный буфер
- работать только через регистры и память
- учитывать, что длина строки задаётся отдельно

### Задание: сортировка строки (Bubble Sort) — **100 баллов**

Напишите программу на ассемблере Intel 8080, работающую в операционной системе **CP/M**.

Программа должна:

1. Считать строку с клавиатуры

   - максимальная длина — **20 символов**
   - ввод завершается нажатием клавиши **Enter**

2. Отсортировать символы строки **по возрастанию**
   (по ASCII-кодам)

3. Вывести отсортированную строку на экран

#### Требования

##### Ввод строки

- строка должна быть сохранена в памяти
- символ **Enter (0Dh)** не входит в строку

##### Обработка строки

Реализуйте подпрограмму:

```text
BubbleSort
```

###### Параметры

- `HL` — адрес начала строки
- `BC` — длина строки

###### Задача

Отсортировать строку **на месте** (in-place), не используя дополнительную память.

```text
для i от 0 до N-1:
    для j от 0 до N-2-i:
        если a[j] > a[j+1]:
            поменять местами
```

#### Подсказки

Сравнение элементов

Для сравнения двух символов используйте инструкцию:

```asm
CMP r
```

или (если второй операнд в памяти):

```asm
CMP M
```

Эта инструкция вычисляет разность между `A` и аргументом,
но результат **не сохраняется**, изменяются только флаги.

После `CMP` можно использовать:

- `JZ` — если элементы равны
- `JC` — если `A < operand`
- `JNC` — если `A ≥ operand`

Обмен значений (swap)

```asm
; HL указывает на a[j+1]

MOV D, M        ; D = a[j+1]
DCX H           ; HL -> &a[j]
MOV A, M        ; A = a[j]

MOV M, D        ; a[j] = a[j+1]
INX H           ; HL -> &a[j+1]
MOV M, A        ; a[j+1] = a[j]
```

- `CMP` не изменяет регистр `A`
- можно безопасно использовать его перед переходами

следите за положением `HL`:

- после `INX H` вы уже на следующем элементе

Перед началом внутреннего цикла:

- сохраняйте адрес начала строки
- каждый проход начинайте с него

#### Ограничения

- не использовать дополнительный буфер
- сортировка должна происходить **в той же области памяти**
- использовать только регистры и память

#### Структура программы

```text
считать строку
определить длину
CALL BubbleSort
вывести строку
```

#### Бонус: игнорировать регистр символов — **20 баллов**

Игнорировать регистр: 'a' и 'A' считать равными.

#### Бонус: оптимизация — **30 баллов**

Оптимизация: завершать сортировку раньше, если массив символов уже отсортирован.

## 📄 Шпаргалка: ввод-вывод в CP/M (BDOS)

Вызов функции операционной системы выполняется так:

```asm
MVI C, <номер функции>
; задать параметры (если нужны)
CALL 5
```

результат (если есть) возвращается обычно в регистре `A`

### Основные функции BDOS

#### 1. Ввод символа с клавиатуры (с эхом)

```asm
MVI C, 1
CALL 5
```

результат:

- символ возвращается в регистре `A`

особенность:

- символ автоматически отображается на экране

#### 2. Вывод одного символа

```asm
MVI C, 2
MOV E, <символ>
CALL 5
```

параметр:

- `E` — символ для вывода

#### 3. Вывод строки

```asm
MVI C, 9
LXI D, <адрес строки>
CALL 5
```

параметры:

- `DE` — адрес строки

важно:

- строка должна заканчиваться символом `$`:

#### 4. Ввод символа без ожидания (опционально)

```asm
MVI C, 6
MVI E, 0FFh
CALL 5
```

результат:

- символ в `A` (если есть)
- иначе `A = 0`

#### 5. Ввод строки

```asm
MVI C, 0Ah
LXI D, <буфер>
CALL 5
```

формат буфера:

```text
[0] — максимальная длина
[1] — фактическая длина
[2..] — введённые символы
```

### Полезные ASCII-коды

| Символ | Код |
| ------ | --- |
| Enter  | 0Dh |
| '0'    | 30h |
| 'A'    | 41h |
| 'a'    | 61h |

### Пример: вывод символа

```asm
MVI C, 2
MVI E, 'A'
CALL 5
```

### Пример: вывод строки

```asm
MVI C, 9
LXI D, MSG
CALL 5

MSG: DB 'HELLO$'
```

### Важно помнить

всегда:

- номер функции записывайте в `C`
- параметры записывайте в другие регистры (зависит от номера функции)

`CALL 5` — точка входа в BDOS
