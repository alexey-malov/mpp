## Задания

### Задание 1: сортировка дат — 40 баллов

Пользователь вводит:

1. Целое число `N` — количество дат
   `1 ≤ N ≤ 10`
2. Далее `N` дат.
   Каждая дата вводится в формате:

```txt
day month year
```

Все значения — целые числа.

В базовой части **предполагается, что все введённые даты корректны**.
Проверку корректности реализовывать не требуется.

---

#### Требуется

1. Считать `N` дат.
2. Отсортировать их в **хронологическом порядке** (от самой ранней к самой поздней).
3. Вывести отсортированные даты в том же формате.


#### Рекомендуемая модель данных

```c
typedef struct
{
    int day;
    int month;
    int year;
} Date;
```

#### Правила сравнения дат

Дата `A` раньше даты `B`, если:

- `A.year < B.year`,
  или
- годы равны, но `A.month < B.month`,
  или
- годы и месяцы равны, но `A.day < B.day`.

---

#### Бонус за проверку корректности дат — 10 баллов

Добавить проверку корректности даты.

Программа должна:

1. Проверять корректность каждой введённой даты.
2. В случае некорректной даты выводить сообщение об ошибке и завершать работу.

##### Требования к проверке

- Месяц должен быть от 1 до 12.
- День должен быть в допустимом диапазоне для данного месяца.
- Учитывать високосные годы.

##### Год является високосным, если:

- делится на 400
  или
- делится на 4, но не делится на 100.

Пример:

- 2000 — високосный
- 1900 — не високосный
- 2024 — високосный

### Задание 2: ближайший населённый пункт — 80 баллов

На плоской планете есть до 10 населённых пунктов. Каждый имеет целочисленные координаты и название.
Путешественник находится в некоторой точке. Нужно найти ближайший(ие) населённый(ые) пункт(ы) по **Манхеттенскому расстоянию**.

#### Формат входных данных

1. Одно целое число `N` — количество населённых пунктов.
   `1 ≤ N ≤ 10`

2. Далее `N` строк, каждая в формате:

    `X Y Name`, где
   - `X`, `Y` — целые числа
   - `Name` — одно слово длиной **до 20 символов** (без учёта `'\0'`)
3. Последняя строка: координаты пользователя

`Ux Uy`


#### Манхэттенское расстояние

Манхэттенское расстояние (расстояние городских кварталов) — это расстояние между двумя точками, если двигаться можно только по горизонтали и вертикали.

Для точек `(x1, y1)` и `(x2, y2)` оно вычисляется так:

```txt
|x1 - x2| + |y1 - y2|
```

То есть модуль разницы по X складываем с модулем разницы по Y.

#### Требования к программе

1. Прочитать `N`, затем массив из `N` населённых пунктов.
2. Прочитать координаты пользователя.
3. Найти минимальное расстояние до населённых пунктов.
4. Вывести **все** населённые пункты, у которых это расстояние минимально.
5. Для каждого выведенного пункта вывести:
   - название,
   - координаты,
   - расстояние до пользователя.

---

#### Формат вывода

Свободный, но должен содержать всю информацию. Например:

Если ближайший один:

```txt
Nearest:
TownA (10, 5) distance = 7
```

Если несколько на одинаковом минимуме:

```txt
Nearest:
TownA (10, 5) distance = 7
TownB (8, 6) distance = 7
```

#### Примеры входных и выходных данных

##### Пример 1

Входные данные:

```txt
5
0 0 Alpha
10 5 Beta
-3 4 Gamma
7 -2 Delta
2 3 Epsilon
3 2
```

Выходные данные:

```txt
Nearest:
Epsilon (2, 3) distance = 2
```

Пояснение:

Координаты пользователя: `(3, 2)`

Считаем расстояния:

- Alpha: `|0−3| + |0−2| = 3 + 2 = 5`
- Beta: `|10−3| + |5−2| = 7 + 3 = 10`
- Gamma: `|-3−3| + |4−2| = 6 + 2 = 8`
- Delta: `|7−3| + |-2−2| = 4 + 4 = 8`
- Epsilon: `|2−3| + |3−2| = 1 + 1 = 2`

Минимальное расстояние — **2**.

##### Пример 2

Вход:

```txt
3
0 0 A
2 0 B
1 1 C
1 0
```

Выход:

```txt
Nearest:
A (0, 0) distance = 1
B (2, 0) distance = 1
C (1, 1) distance = 1
```
