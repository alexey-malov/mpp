## Задания

### Задание 1: Сборка числа `float` из битовых компонент — **50 баллов**

В этом задании необходимо реализовать сборку числа с плавающей запятой формата IEEE 754 (тип `float`)
из отдельных компонент: знака, экспоненты и мантиссы.

#### Часть 1. Реализация функции

Реализуйте функцию:

```c
int BuildFloat(bool sign, uint8_t exponent, uint32_t mantissa, float* result);
```

Функция должна:

1. Принимать параметры:

   - `sign` — знак числа (0 — положительное, 1 — отрицательное)
   - `exponent` — экспонента (0..255)
   - `mantissa` — мантисса (23 бита, младшие биты числа)
   - `result` — указатель на переменную, в которую будет записан результат

2. Выполнять:

   - сборку 32-битного представления числа формата IEEE 754:

     ```txt
     [ sign | exponent | mantissa ]
     ```

   - копирование полученных бит в переменную типа `float` с использованием `memcpy`

3. Обрабатывать ошибки:

   - если `mantissa` не помещается в 23 бита (больше `0x7FFFFF`), функция должна вернуть ненулевое значение
   - в остальных случаях возвращать 0

#### Часть 2. Тестирование

С помощью реализованной функции постройте и выведите следующие значения:

1. Положительная бесконечность (+∞)
2. Отрицательная бесконечность (−∞)
3. Число −1
4. Число 5
5. Число −0.25
6. Число +0

Для каждого значения:

- выведите полученное число (`printf`)
- при необходимости дополнительно выведите его битовое представление

#### Часть 3. Ввод от пользователя

Реализуйте в программе взаимодействие с пользователем:

1. Считывает с клавиатуры:
   - знак (0 или 1)
   - экспоненту (целое число 0..255)
   - мантиссу (в шестнадцатеричном формате)
2. Вызывает `BuildFloat`
3. В случае успеха:
   - выводит полученное значение типа `float`
4. В случае ошибки:
   - выводит сообщение об ошибке

### Задание 2: Путешествие по бесконечному океану — **80 баллов**

Поверхность плоской бесконечной планеты полностью покрыта водой.
На этой планете расположены круглые острова.

Каждый остров задаётся:

- координатами центра $(x_i, y_i)$
- радиусом $r_i$

Вы — путешественник, находящийся на плоту в точке $(x_0, y_0)$.

Вы выбираете направление движения, задаваемое вектором $(dx, dy)$.

Плот начинает движение по лучу:

$$
(x, y) = (x_0, y_0) + t * (dx, dy),  t ≥ 0
$$

#### Задача

Необходимо определить:

- достигнет ли плот какого-либо острова
- если да — то какого именно (первого по ходу движения)

Плот считается достигшим острова, если он **хотя бы касается его границы**.

Если ни один остров не будет достигнут, плот будет двигаться бесконечно.

#### 📥 Входные данные

1. Начальная точка:

    ```txt
    x0 y0
    ```

2. Направление движения:

    ```txt
    dx dy
    ```

3. Количество островов:

    ```text
    n
    ```

4. Далее `n` строк:

    ```text
    xi yi ri
    ```

---

#### Выходные данные

- индекс острова (от 0 до n-1), к которому плот причалит первым
- или `-1`, если плот не достигнет ни одного острова

#### ⚙️ Требования

1. Использовать тип `double`
2. Корректно обрабатывать:

   - касание (дискриминант = 0)
   - случай, когда плот уже находится внутри острова

3. Учитывать только пересечения при `t ≥ 0` (плот плывёт вперёд)
4. Если пересечений несколько — выбрать пересечение с **минимальным положительным t**

#### Подсказка

Для каждого острова задача сводится к пересечению луча и окружности.

Подставьте уравнение луча в уравнение окружности:

$$
(x - x_i)^2 + (y - y_i)^2 = r_i^2
$$

Вы получите квадратное уравнение относительно `t`:

```text
At^2 + Bt + C = 0
```

- Дискриминант равен $D = B^2 - 4AC$
- если `D < 0` → пересечения нет
- если `D = 0` → касание
- если `D > 0` → два пересечения

Из найденных значений `t` нужно выбрать:

- только `t ≥ 0`
- минимальное

#### Особые случаи

- старт внутри острова → считаем, что плот уже достиг его (`t = 0`)
- `(dx, dy) = (0, 0)` → плот не движется. Если плот изначально не на острове, то никуда он не приплывёт

---

#### Бонус за вывод координат и времени прибытия на остров — 20 баллов

- вывести координаты точки пересечения и время $t$, когда произойдёт прибытие
- обработать случай, когда плот касается нескольких островов одновременно
- добавить epsilon для сравнения с нулём
