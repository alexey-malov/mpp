## Задания

### Задание 1: Сборка числа `float` из битовых компонент — **50 баллов**

В этом задании необходимо реализовать сборку числа с плавающей запятой формата IEEE 754 (тип `float`)
из отдельных компонент: знака, экспоненты и мантиссы.

#### Часть 1. Реализация функции

Реализуйте функцию:

```c
int BuildFloat(bool sign, uint8_t exponent, uint32_t mantissa, float* result);
```

Функция должна:

1. Принимать параметры:

   - `sign` — знак числа (0 — положительное, 1 — отрицательное)
   - `exponent` — экспонента (0..255)
   - `mantissa` — мантисса (23 бита, младшие биты числа)
   - `result` — указатель на переменную, в которую будет записан результат

2. Выполнять:

   - сборку 32-битного представления числа формата IEEE 754:

     ```txt
     [ sign | exponent | mantissa ]
     ```

   - копирование полученных бит в переменную типа `float` с использованием `memcpy`

3. Обрабатывать ошибки:

   - если `mantissa` не помещается в 23 бита (больше `0x7FFFFF`), функция должна вернуть ненулевое значение
   - в остальных случаях возвращать 0

#### Часть 2. Тестирование

С помощью реализованной функции постройте и выведите следующие значения:

1. Положительная бесконечность (+∞)
2. Отрицательная бесконечность (−∞)
3. Число −1
4. Число 5
5. Число −0.25
6. Число +0

Для каждого значения:

- выведите полученное число (`printf`)
- при необходимости дополнительно выведите его битовое представление

#### Часть 3. Ввод от пользователя

Реализуйте в программе взаимодействие с пользователем:

1. Считывает с клавиатуры:
   - знак (0 или 1)
   - экспоненту (целое число 0..255)
   - мантиссу (в шестнадцатеричном формате)
2. Вызывает `BuildFloat`
3. В случае успеха:
   - выводит полученное значение типа `float`
4. В случае ошибки:
   - выводит сообщение об ошибке

### Задание 2: Путешествие по бесконечному океану — **80 баллов**

Поверхность плоской бесконечной планеты полностью покрыта водой.
На этой планете расположены круглые острова.

Каждый остров задаётся:

- координатами центра $(x_i, y_i)$
- радиусом $r_i$

Вы — путешественник, находящийся на плоту в точке $(x_0, y_0)$.

Вы выбираете направление движения, задаваемое вектором $(dx, dy)$.

Плот начинает движение по лучу:

$$
(x, y) = (x_0, y_0) + t * (dx, dy),  t ≥ 0
$$

#### Задача

Необходимо определить:

- достигнет ли плот какого-либо острова
- если да — то какого именно (первого по ходу движения)

Плот считается достигшим острова, если он **хотя бы касается его границы**.

Если ни один остров не будет достигнут, плот будет двигаться бесконечно.

#### Входные данные

1. Начальная точка:

    ```txt
    x0 y0
    ```

2. Направление движения:

    ```txt
    dx dy
    ```

3. Количество островов:

    ```text
    n
    ```

4. Далее `n` строк:

    ```text
    xi yi ri
    ```

---

#### Выходные данные

- индекс острова (от 0 до n-1), к которому плот причалит первым
- или `-1`, если плот не достигнет ни одного острова

#### Требования

1. Использовать тип `double`
2. Корректно обрабатывать:

   - касание (дискриминант = 0)
   - случай, когда плот уже находится внутри острова

3. Учитывать только пересечения при `t ≥ 0` (плот плывёт вперёд)
4. Если пересечений несколько — выбрать пересечение с **минимальным положительным t**

#### Подсказка

Для каждого острова задача сводится к пересечению луча и окружности.

Подставьте уравнение луча в уравнение окружности:

$$
(x - x_i)^2 + (y - y_i)^2 = r_i^2
$$

Вы получите квадратное уравнение относительно `t`:

```text
At^2 + Bt + C = 0
```

- Дискриминант равен $D = B^2 - 4AC$
- если `D < 0` → пересечения нет
- если `D = 0` → касание
- если `D > 0` → два пересечения

Из найденных значений `t` нужно выбрать:

- только `t ≥ 0`
- минимальное

#### Особые случаи

- старт внутри острова → считаем, что плот уже достиг его (`t = 0`)
- `(dx, dy) = (0, 0)` → плот не движется. Если плот изначально не на острове, то никуда он не приплывёт

---

#### Бонус за вывод координат и времени прибытия на остров — **20 баллов**

- вывести координаты точки пересечения и время $t$, когда произойдёт прибытие
- обработать случай, когда плот касается нескольких островов одновременно
- добавить epsilon для сравнения с нулём


### Задание 3: Обратная матрица — **150 баллов**

В этом задании необходимо реализовать программу, которая работает с квадратными матрицами произвольного размера,
заданными во время выполнения.

В первой строке стандартного ввода передаётся целое число `N` (`N >= 1`) — размер квадратной матрицы.

В следующих `N` строках передаются по `N` вещественных чисел (`double`), задающих элементы матрицы.

Программа должна:

1. Прочитать матрицу из стандартного ввода с проверкой корректности ввода.
2. Построить для неё обратную матрицу.
3. Если обратная матрица существует, умножить исходную матрицу на найденную обратную.
4. Проверить, что результат является единичной матрицей с точностью до некоторого `epsilon`.
5. Если исходная матрица вырождена и обратной матрицы не существует, вывести:

   ```txt
   Matrix is singular
   ```

   Если обратная матрица существует, нужно вывести обратную матрицу (по строкам, элементы в строке разделяются пробелом).

#### Цель задания

В этом задании предстоит закрепить:

- работу с динамической памятью
- хранение матриц произвольного размера
- арифметику с числами типа `double`
- сравнение чисел с плавающей запятой с использованием `epsilon`
- решение математической задачи обращения матрицы

#### Представление матрицы в памяти

Матрицу необходимо хранить в динамической памяти.

Один из рекомендуемых вариантов — выделить один непрерывный блок памяти под все элементы матрицы
и хранить их в одномерном массиве.

Для этого используйте структуру:

```c
typedef struct {
    int numRows;
    int numColumns;
    double* items; // указатель на данные (в куче)
} Matrix;
```

Элемент матрицы с индексами `(row, column)` можно хранить по индексу:

```text
row * numColumns + column
```

#### Необходимые функции

Реализуйте как минимум следующие функции:

```c
// Создаёт матрицу нужного размера (элементы не инициализированы)
// и возвращает 0 в случае успеха.
// Выходной параметр m хранит параметры созданной матрицы.
int CreateMatrix(int numRows, int numColumns, Matrix* m);

// Освобождает память, занимаемую матрицей,
// и сбрасывает её размеры и указатель на данные.
void DestroyMatrix(Matrix* m);

// Возвращает значение элемента матрицы.
// Если индекс выходит за допустимые пределы, вызывает функцию abort().
double GetMatrixItemValue(const Matrix* m, int row, int column);

// Устанавливает значение элемента матрицы.
// Если индекс выходит за допустимые пределы, вызывает функцию abort().
void SetMatrixItemValue(const Matrix* m, int row, int column, double value);
```

Рекомендуется реализовать и дополнительные функции, например:

- печать матрицы
- копирование матрицы
- умножение матриц
- создание единичной матрицы
- сравнение двух матриц с `epsilon`

#### Входные данные

Формат входа:

```txt
N
a11 a12 ... a1N
a21 a22 ... a2N
...
aN1 aN2 ... aNN
```

Пример:

```txt
3
1 0 3
0 1 4
0 0 1
```

#### Выходные данные

Если матрица вырождена:

```txt
Matrix is singular
```

Если матрица не вырождена:

```txt
1 0 -3
0 1 -4
0 0 1
```

Числа с плавающей запятой выводите с точностью по умолчанию.

#### Как искать обратную матрицу

Допускается использовать любой корректный метод, например:

- метод Крамера
- метод Гаусса-Жордана
- метод алгебраических дополнений
- другой эквивалентный метод

Для матриц общего размера наиболее практичным является метод Гаусса-Жордана.

#### Проверка результата

После построения обратной матрицы нужно умножить исходную матрицу $A$ на обратную $A^{-1}$ и получить матрицу $R$.

Матрица $R$ должна быть единичной с точностью до некоторого $\epsilon$.

То есть:

- на главной диагонали элементы должны быть близки к `1.0`
- вне диагонали элементы должны быть близки к `0.0`

Например:

```c
fabs(value - expected) < epsilon
```

Здесь нельзя использовать прямое сравнение `==` для чисел типа `double`.

##### 1. Проверка ввода

Программа должна корректно обработать ошибочный ввод.

Например:

- не удалось прочитать `N`
- `N < 1`
- не удалось прочитать очередной элемент матрицы
- не удалось выделить память

В таких случаях программа должна завершаться корректно.

##### 2. Проверка вырожденности

Если в процессе обращения оказывается, что матрица вырождена, нужно вывести:

```txt
Matrix is singular
```

##### 3. Корректная работа с памятью

Вся выделенная память должна быть освобождена. Утечек памяти быть не должно.

#### Рекомендации

- используйте `double`
- выберите разумное значение `epsilon`, например `1e-9`
- разбейте решение на небольшие функции
- отдельно протестируйте:

  - создание и удаление матрицы
  - доступ к элементам
  - умножение матриц
  - проверку единичной матрицы
  - обращение матрицы
