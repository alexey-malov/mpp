# Лабораторная работа №1

## Задания

### Фибоначчи - 20 баллов

Напишите программу на языке C, которая вычисляет и выводит **n-е число последовательности Фибоначчи**.

Последовательность Фибоначчи определяется следующим образом:

* $F_0 = 0$
* $F_1 = 1$
* $F_n = F_{n − 1} + F_{n − 2}$ для $n ≥ 2$

#### Входные данные

На стандартный ввод подаётся одно целое число `n` — номер числа Фибоначчи.
Нумерация начинается с нуля.

#### Выходные данные

Программа должна вывести одно целое число — значение `F(n)`.

#### Требования и ограничения

* Используйте тип `int`.
* Реализуйте вычисление с помощью цикла `while` или `for`.
* Рекурсивную реализацию использовать **не нужно**.
* Перед вычислением проверьте корректность ввода:

  * если ввод некорректен или `n < 0`, выведите сообщение об ошибке и завершите программу.
* Для ввода и вывода используйте `scanf` и `printf`.

#### Примеры

Ввод

```txt
0
```

Вывод

```txt
0
```

---

Ввод

```txt
1
```

Вывод

```txt
1
```

---

Ввод

```txt
7
```

Вывод

```txt
13
```

#### Пояснение

В этом задании вы должны:

* считать целое число из стандартного ввода;
* обработать граничные случаи (`n = 0`, `n = 1`);
* использовать арифметические операции и цикл для вычисления результата;
* аккуратно работать с переменными и условными операторами.
