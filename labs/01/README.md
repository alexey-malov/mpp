## Критерии оценивания работы

- Для получения оценки "удовлетворительно" нужно набрать не менее 60 баллов.
- На оценку "хорошо" нужно набрать не менее 100 баллов.
- Для получения оценки "отлично" нужно набрать не менее 140 баллов.

## Задания

### Задание 1. Фибоначчи - 20 баллов

Напишите программу на языке C, которая вычисляет и выводит **n-е число последовательности Фибоначчи**.

Последовательность Фибоначчи определяется следующим образом:

- $F_0 = 0$
- $F_1 = 1$
- $F_n = F_{n − 1} + F_{n − 2}$ для $n ≥ 2$

#### Входные данные

На стандартный ввод подаётся одно целое число `n` — номер числа Фибоначчи.
Нумерация начинается с нуля.

#### Выходные данные

Программа должна вывести одно целое число — значение `F(n)`.

#### Требования и ограничения

- Используйте тип `int`.
- Реализуйте вычисление с помощью цикла `while` или `for`.
- Рекурсивную реализацию использовать **не нужно**.
- Перед вычислением проверьте корректность ввода:
  - если ввод некорректен или `n < 0`, выведите сообщение об ошибке и завершите программу.
- Для ввода и вывода используйте `scanf` и `printf`.

#### Примеры

Ввод

```txt
0
```

Вывод

```txt
0
```

---

Ввод

```txt
1
```

Вывод

```txt
1
```

---

Ввод

```txt
7
```

Вывод

```txt
13
```

#### Пояснение

В этом задании вы должны:

- считать целое число из стандартного ввода;
- обработать граничные случаи (`n = 0`, `n = 1`);
- использовать арифметические операции и цикл для вычисления результата;
- аккуратно работать с переменными и условными операторами.

### Задание 2. Анализ последовательности целых чисел - 40 баллов

Напишите программу на языке C, которая читает **целые числа из стандартного ввода до конца файла (EOF)**
и вычисляет следующие характеристики введённой последовательности:

- общее количество введённых чисел;
- сумму всех чисел;
- минимальное и максимальное значение (если введено хотя бы одно число);
- количество чётных и количество нечётных чисел (если введено хотя бы одно число).

#### Входные данные

На стандартный ввод подаётся последовательность целых чисел, разделённых пробелами и/или переводами строки.
Ввод заканчивается концом файла (EOF).

#### Выходные данные

Программа должна вывести:

- количество чисел;
- сумму чисел;
- минимальное и максимальное значение — **только если было введено хотя бы одно число**;
- количество чётных и нечётных чисел.

Формат вывода может быть произвольным, но должен быть читаемым и однозначным.

#### Требования и ограничения

- Используйте тип `int` для хранения чисел.
- Для чтения входных данных используйте `scanf`.
- Чтение должно продолжаться до тех пор, пока `scanf` успешно считывает число.
- Используйте цикл `while`.
- Обработайте ситуацию, когда во входных данных нет ни одного числа.
- Для определения чётности используйте оператор `%`.

#### Пример

Ввод

```txt
3 7 -2 10 5
```

Вывод

```txt
Count: 5
Sum: 23
Min: -2
Max: 10
Even: 2
Odd: 3
```

---

Ввод

```txt
```

(пустой ввод)

Вывод

```txt
Count: 0
Sum: 0
```

#### Пояснение

В этом задании вы должны:

- организовать чтение данных до конца файла;
- корректно проверять результат `scanf`;
- аккуратно инициализировать переменные;
- учитывать граничные случаи (пустой ввод);

### Задание 3. Угадай число - 50 баллов

Напишите программу на языке C, которая **угадывает целое число**, загаданное пользователем, в диапазоне **от 1 до 100 включительно**.

Программа работает в диалоговом режиме:

1. Пользователь загадывает целое число от 1 до 100.
2. Программа делает предположение и выводит его на экран.
3. Пользователь отвечает одним символом:
   - `<` — загаданное число **меньше** предложенного,
   - `>` — загаданное число **больше** предложенного,
   - `=` — программа угадала число.
4. Программа, используя ответы пользователя, должна найти загаданное число **методом двоичного поиска**.

#### Взаимодействие с пользователем

После каждого предположения программа ожидает ввод **одного символа**: `<`, `>` или `=`.

#### Требования и ограничения

- Диапазон поиска изначально: от `1` до `100`.
- Программа должна использовать **двоичный поиск**.
- Используйте цикл `while`.
- Для чтения ответа пользователя используйте `getchar`.
- Не используйте рекурсию.
- Используйте тип `int`.

#### Обработка ошибок

Программа должна обнаруживать ситуацию, когда пользователь вводит противоречивые ответы.

Например:

- пользователь говорит, что число больше 100 или меньше 1;
- пользователь своими ответами делает диапазон поиска пустым (`low > high`).

В этом случае программа должна вывести сообщение об ошибке, например:

```txt
Ошибка: противоречивые ответы пользователя.
```

и завершить работу.

#### Пример работы программы

```txt
Make up a number from 1 до 100.
My guess: 50
Your answer (<, >, =): >
My guess: 75
Your answer (<, >, =): <
My guess: 62
Your answer (<, >, =): =
Number is guessed!
```

#### Пояснение

В этом задании вы должны:

- реализовать классический алгоритм двоичного поиска;
- обновлять границы диапазона на основе ответов пользователя;
- аккуратно работать с вводом одиночных символов;
- отслеживать логические ошибки во вводе;
- использовать условия, циклы и арифметику.

#### Подсказка

Если диапазон поиска стал пустым, значит пользователь дал противоречивые ответы.

### Задание 4. Подсчёт количества слов - 40 баллов

Напишите программу на языке C, которая читает текст **из стандартного ввода (stdin) до конца файла (EOF)**
и подсчитывает **количество слов** во входных данных.

**Словом** считается последовательность из **одного или более** символов, каждый из которых является:

- цифрой (`0–9`) **или**
- буквой латинского алфавита в любом регистре (`a–z`, `A–Z`).

Все остальные символы считаются **разделителями**.
К разделителям относятся, в частности:

- пробелы,
- табуляции,
- переводы строки,
- знаки пунктуации,
- любые символы с кодами **меньше 32**.

Слова могут быть разделены **произвольным количеством** разделителей.

#### Входные данные

На стандартный ввод подаётся произвольный текст.
Ввод завершается концом файла (EOF).

#### Выходные данные

Программа должна вывести одно целое число — **количество слов** во входном тексте.

#### Требования и ограничения

- Для чтения входных данных используйте `getchar`.
- Не используйте массивы, строки и стандартные функции для работы со строками.
- Не используйте заголовочный файл `<ctype.h>`.
- Анализ символов выполняйте с помощью сравнений (`>=`, `<=`, `<`, `>`, `==`, `!=`).
- Программа должна корректно обрабатывать пустой ввод.

#### Примеры

Ввод

```txt
Hello, world!
```

Вывод

```txt
2
```

---

Ввод

```txt
One   two,three
four
```

Вывод

```txt
4
```

---

Ввод

```txt
123  abc45 !!!  7
```

Вывод

```txt
3
```

---

#### Пояснение

В этом задании вы должны:

- читать входные данные посимвольно до EOF;
- определять, является ли символ частью слова;
- отслеживать переходы между состояниями «внутри слова» и «вне слова»;
- аккуратно работать с условиями и циклами.

---

#### Подсказка

Удобно хранить флаг, который показывает, находитесь ли вы сейчас внутри слова.
Новое слово начинается тогда, когда вы встречаете букву или цифру, находясь вне слова.
