## Задания

### Задание 1: Сортировка строк с использованием `qsort` — **30 баллов**

#### Условие

Программа считывает из стандартного ввода число `N` — количество строк.

Далее вводятся `N` строк текста.

Необходимо:

1. Прочитать все строки в динамическую память
2. Отсортировать их **по возрастанию (лексикографически)** с использованием функции `qsort`
3. Вывести отсортированные строки в стандартный вывод

#### Формат входных данных

- В первой строке содержится целое число `N` (`N ≥ 0`)
- Далее следуют `N` строк произвольной длины (в пределах разумных ограничений)

#### Формат выходных данных

- Вывести `N` строк в отсортированном порядке, по одной строке на строку

#### Требования

- Использовать функцию `qsort` из стандартной библиотеки
- Реализовать собственную функцию-компаратор
- Хранить строки в виде массива указателей (`char*`)
- Память под строки должна выделяться динамически
- Корректно освободить всю выделенную память

#### Подсказки

- Компаратор должен иметь сигнатуру:

```c
int cmp(const void* a, const void* b);
```

- Элементы массива — это указатели на строки (`char*`), поэтому в компараторе потребуется двойное приведение:

```c
const char* s1 = *(const char**)a;
const char* s2 = *(const char**)b;
```

- Для сравнения строк используйте `strcmp`

#### Пример

##### Ввод:

```txt
4
banana
apple
pear
apricot
```

##### Вывод:

```txt
apple
apricot
banana
pear
```

### Задание 2: Полиморфизм на C с использованием указателей на функции — **100 баллов**

#### Условие

Необходимо реализовать модуль `shapes`, поддерживающий работу с тремя типами фигур:

- `Circle` — окружность
- `Rectangle` — прямоугольник
- `Triangle` — треугольник

Для всех фигур должен использоваться единый интерфейс `Shape`.
Реализация должна быть построена по полиморфной схеме на языке C:
через непрозрачный тип, указатели на функции и таблицу виртуальных функций.

#### Поддерживаемые фигуры

##### Circle

Задаётся:

- координатами центра
- радиусом
- цветом

##### Rectangle

Задаётся:

- координатами левого верхнего угла
- шириной
- высотой
- цветом

##### Triangle

Задаётся:

- координатами трёх вершин
- цветом

#### Требуемые операции над фигурами

Для каждой фигуры должны быть доступны следующие операции:

- `ShapeGetArea` — вычисление площади
- `ShapeGetPerimeter` — вычисление периметра
- `ShapeDraw` — вывод фигуры в текстовом виде

Клиентский код должен работать только с указателями типа `Shape*`, не зная конкретного типа фигуры.

#### Формат входных данных

В первой строке вводится целое число `N` — количество фигур.

В следующих `N` строках записаны описания фигур в одном из следующих форматов:

```text
circle x y radius color
rectangle left top width height color
triangle x1 y1 x2 y2 x3 y3 color
```

Цвет задаётся строкой в формате:

```text
#rrggbb
```

где `rr`, `gg`, `bb` — шестнадцатеричные значения компонент цвета.

#### Формат выходных данных

##### 1. Сначала необходимо отсортировать фигуры по возрастанию площади и вывести их в формате:

```text
circle x y radius color area perimeter
rectangle left top width height color area perimeter
triangle x1 y1 x2 y2 x3 y3 color area perimeter
```

##### 2. Затем необходимо отсортировать те же фигуры по убыванию периметра и снова вывести их в том же формате.

#### Требования к реализации

##### Архитектура

Необходимо реализовать модуль `shapes`, в котором:

- тип `Shape` объявлен как неполный в заголовочном файле
- конкретные структуры фигур скрыты в `.c`-файле
- выбор реализации операций выполняется через таблицу виртуальных функций

##### Интерфейс модуля

В модуле должны быть предусмотрены:

- создание окружности
- создание прямоугольника
- создание треугольника
- уничтожение фигуры
- получение площади
- получение периметра
- вывод фигуры

##### Работа программы

Основная программа должна:

1. прочитать `N`
2. прочитать все фигуры
3. создать массив указателей `Shape*`
4. отсортировать фигуры по площади с помощью `qsort`
5. вывести результат
6. отсортировать фигуры по периметру с помощью `qsort`
7. вывести результат
8. освободить всю выделенную память

#### Дополнительные требования

- Для сортировки использовать `qsort`
- Для вычисления длины стороны треугольника использовать расстояние между точками
- Для вычисления площади треугольника можно использовать формулу Герона или формулу через координаты
- Все объекты должны создаваться динамически
- Вся выделенная память должна быть освобождена
- Необходимо корректно обрабатывать ошибки ввода

#### Подсказки

##### 1. Полиморфизм

Базовая структура `Shape` может хранить указатель на таблицу виртуальных функций.

##### 2. Сортировка

Для `qsort` потребуются компараторы:

- по возрастанию площади
- по убыванию периметра

##### 3. Вывод

Функция `ShapeDraw` должна выводить только данные фигуры,
а площадь и периметр можно выводить отдельно через `ShapeGetArea` и `ShapeGetPerimeter`.

#### Пример входных данных

```text
3
circle 0 0 10 #ff0000
rectangle -1 2 5 3 #00ff00
triangle 0 0 3 0 0 4 #0000ff
```

#### Пример вывода

Численные значения в примере условны.

```text
triangle 0 0 3 0 0 4 #0000ff 6.00 12.00
rectangle -1 2 5 3 #00ff00 15.00 16.00
circle 0 0 10 #ff0000 314.16 62.83

circle 0 0 10 #ff0000 314.16 62.83
rectangle -1 2 5 3 #00ff00 15.00 16.00
triangle 0 0 3 0 0 4 #0000ff 6.00 12.00
```

#### Что должно получиться

В результате должна получиться программа, в которой:

- разные типы фигур обрабатываются через единый интерфейс
- конкретная реализация выбирается во время выполнения
- сортировка выполняется через `qsort` и функции-компараторы
- указатели на функции используются и для полиморфизма, и для сортировки
