## Задания

### Задание 1: Дамп памяти — 50 баллов

#### Цель

Написать функцию, которая выводит содержимое блока памяти в удобном для чтения виде,
а затем использовать её для исследования того, как в памяти представлены разные типы данных.

#### Часть 1. Функция `PrintDump`

Необходимо реализовать функцию:

```c
void PrintDump(const uint8_t* data, size_t size);
```

Функция должна выводить дамп блока памяти по **16 байтов в строке**.

Для каждой строки нужно вывести:

1. адрес первого байта строки в шестнадцатеричном виде
   Для этого можно использовать:

   ```c
   printf("%p", addr);
   ```

   Адрес начала строки можно вычислять как `data + offset`.

2. до 16 байтов в шестнадцатеричном виде

3. символьное представление этих байтов
   Печатать символ только тогда, когда его код находится в диапазоне [32, 255],
   в остальных случаях выводить точку.

Если в последней строке меньше 16 байтов, нужно корректно вывести только оставшиеся байты.

Пример формата вывода:

```txt
000001B74: 20 20 43 61 6C 6C 20 43 │ 6C 6F 73 65 43 6C 69 70    Call CloseClip
000001B84: 62 6F 61 72 64 0D 0A 20 │ 20 20 20 45 6E 64 20 49  board..    End I
000001B94: 66 0D 0A 45 6E 64 20 53 │ 75 62 0D 0A 0D 0A        f..End Sub....
```

#### Часть 2. Исследование представления данных

С помощью функции `PrintDump` нужно вывести дамп следующих объектов.

##### 1. Массив из 6 элементов типа `int`

Создать массив:

```c
int a[6];
```

Значения элементов вводятся со стандартного ввода.

После ввода вывести дамп всего массива.

---

##### 2. Строка

Вывести дамп строки: "A quick brown fox jumps over the lazy dog".
**Дамп должен включать завершающий нулевой символ**.

---

##### 3. Структура `Employee`

Дана структура:

```c
struct Employee
{
    int birthYear;
    short birthMonth;
    char birthDay;
    char name[51]; // Имя (50 символов максимум)
    int64_t salary;
};
```

Поля структуры вводятся со стандартного ввода, затем выводится дамп всей структуры. Имя может содержать пробелы.
Нужно прочитать имя через `fgets` до символа перевода строки строки, но не более 50 символов.

##### Заголовки перед каждым дампом

Для наглядности перед каждым дампом печатайте заголовок, например:

```txt
Dump of int array:
Dump of string:
Dump of Employee:
```

Реализовать функцию

```c
void PrintDump(const uint8_t* data, size_t size);
```

#### Вопросы для защиты лабораторной работы

1. Сколько байтов занимает `int` на вашей платформе?
2. В каком порядке лежат байты целого числа?
3. Почему строка заканчивается нулевым байтом?
4. Есть ли padding в структуре `Employee`?
5. Как изменится дамп и размер структуры `Employee`, если поменять порядок полей в структуре?
6. Какой максимальный размер может иметь поле `name` на вашей платформе, без увеличения размера структуры `Employee`?
   Аргументируйте свой ответ.
