## Критерии оценивания работы

- Для получения оценки "удовлетворительно" нужно набрать не менее X баллов.
- На оценку "хорошо" нужно набрать не менее Y баллов.
- Для получения оценки "отлично" нужно набрать не менее Z баллов.

## Задания

### Задание 1. Палинндром — **30 баллов**

Написать программу на языке C, которая:

1. Считывает строки со стандартного ввода.
2. Продолжает работу до наступления `EOF`.
3. Для каждой считанной строки проверяет, является ли она палиндромом.
4. Выводит в стандартный вывод только те строки, которые являются палиндромами.

---

#### Определение

Строка считается палиндромом, если она читается одинаково слева направо и справа налево.

Для данного задания:

- регистр символов учитывать;
- пробелы и прочие символы учитывать;
- символ перевода строки `'\n'` не должен участвовать в проверке.

---

#### Пример

Вход:

```txt
level
test
radar
hello
abba
```

Выход:

```txt
level
radar
abba
```

---

#### Требования

- Использовать стандартный ввод и вывод.
- Корректно обрабатывать окончание ввода (`EOF`).
- Не использовать функцию `strrev` (если она доступна).
- Проверку палиндрома реализовать самостоятельно.
- Разрешается использовать функции из `<string.h>`.

---

#### Методические рекомендации

- Для чтения строки рекомендуется использовать `fgets`.
- Необходимо удалить символ `'\n'`, если он присутствует.
- Длину строки можно определить с помощью `strlen`.
- Проверку удобно реализовать сравнением символов с начала и конца строки с постепенным продвижением к центру.

---

#### Бонус за игнорирование пробелов и знаков препинания — **10 баллов**

Бонус начисляется, если приложение будет игнорировать пробелы и знаки препинания.

Вход:

```txt
madam, i'm adam
```

Выход:

```txt
madam, i'm adam
```

#### Бонус за нечувствительность к регистру — **10 баллов**

Бонус начисляется за нечувствительность к регистру.

Вход:

```txt
Level
```

Выход:

```txt
Level
```

### Задание 2. Top 3 строки — **50 баллов**

Написать программу на языке C, которая:

1. Считывает из стандартного ввода целое число `N` — количество строк.
2. Затем считывает `N` строк произвольной длины.
3. Определяет среди них три строки, которые лексикографически больше остальных.
4. Выводит эти строки в порядке убывания лексикографического порядка (от наибольшей к меньшей).
5. Если `N < 3`, вывести все строки, отсортированные по убыванию.

---

#### Лексикографический порядок

Сравнение строк должно выполняться с использованием функции `strcmp`.

Строка `a` считается больше строки `b`, если:

```txt
strcmp(a, b) > 0
```

---

#### Пример

Вход:

```txt
5
apple
pear
banana
orange
plum
```

Выход:

```txt
plum
pear
orange
```

---

#### Требования

- Строки имеют произвольную длину.
- Память под каждую строку должна выделяться динамически.
- После завершения работы вся выделенная память должна быть освобождена.
- Разрешается использовать функции `<string.h>`.

---

#### Методические рекомендации

- Использовать функцию чтения строки произвольной длины.
- Для решения задачи заведите массив из трех указателей `char*`
  и в процессе чтения сохраняйте в нём три (или меньше) текущих максимума
- Обязательно корректно обрабатывайте случай `N < 3`.

---

#### Бонус за обработку строк с игнорированием регистра символов — **20 баллов**

Реализуйте сортировку строк с игнорированием регистра символов. Для этого напишите свою версию функции сравнения строк,
которая при помощи функций `tolower` или `toupper` переводит сравниваемые
символы к нижнему регистру.

Внимание: сами строки не должны изменяться при чтении или при выводе.
